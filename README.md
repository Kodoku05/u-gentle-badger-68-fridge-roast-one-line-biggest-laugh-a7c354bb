A one-line roast of a smart fridge whose firmware update ruins dinner and whose support system considers that a resolution. This deterministic Node.js entry writes the same original joke to `/output/entry.txt` on every run and checks the 200-character limit using only the standard library.

## Run it

Requires Node.js 22.18 or later and permission to create `/output`.

```sh
node main.ts
```
